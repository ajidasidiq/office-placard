A program that writes a single one-line museum placard for an ordinary office object — the paper shredder — treated as an ancient artifact, for make.fun's "Office Artifacts: The One-Line Placard Contest".

> Paper Shredder, c. 2004. Steel teeth, one appetite. Ritual device for the unmaking of evidence. Last fed the morning the auditors arrived. Gift of Legal.

## Run it

```sh
node main.ts
```

It writes the placard (153 characters) to `/output/entry.txt`.
